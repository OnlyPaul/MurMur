# Murmur — Marketing site UI kit

Single-page landing site, built from the design system. Open `index.html`.

## Components
- `SiteNav.jsx` — sticky top nav with white download CTA.
- `Hero.jsx` — headline + subhead + waveform glow + app-icon dock.
- `FeatureGrid.jsx` — 3-up dark cards on the surface ladder.
- `InstallBlock.jsx` — `brew install murmur` callout with copy button.
- `Footer.jsx` — 5-column link footer with newsletter input.
